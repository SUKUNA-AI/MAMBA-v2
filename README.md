# Гибридная MAMBA2 для задач регрессии: Предсказание гранулометрии на телеметрических данных

## Описание задачи
В данном проекте представлена адаптация гибридной модели MAMBA2 для решения задачи регрессии на телеметрических данных горно-обогатительного процесса. Целью было предсказание двух гранулометрических характеристик:
- **Гранулометрия 1** (значения от 0 до 100),
- **Гранулометрия 2** (значения от 0 до 100).

Эти параметры отражают распределение размеров частиц и измеряются в процентах (от 0 до 100). Модель обучалась на данных телеметрии с минимальной предобработкой, что позволило оценить её устойчивость к шумам и необработанным входным данным.

## Особенности подготовки данных
Очистка данных практически не проводилась. Использовались сырые телеметрические данные с 33 входными признаками, собранными с частотой 1 минута в течение последовательностей длиной 60 минут (`seq_len=60`). Для улучшения качества предсказания в `TelemetryPreprocessor` добавлялись дополнительные признаки, такие как:
- Соотношение мощности к подаче материала (энергоэффективность),
- Соотношение воды к подаче (разбавление),
- Скользящие статистики (среднее и стандартное отклонение),
- Временные разности (скорость изменения).

Эти признаки проецировались в скрытое пространство размером `d_model=256` с добавлением позиционного кодирования.

## Архитектура модели
Модель `PulpSieveModel` представляет собой гибридную архитектуру, сочетающую в себе:
1. **Mamba2**: Механизм обработки последовательностей на основе состояния (SSM) с параметрами:
   - `d_state=128` (размер состояния),
   - `headdim=64` (размер головы),
   - `expand=2` (фактор расширения),
   - Параллельное сканирование для эффективной обработки длинных последовательностей.
2. **Multi-Head Attention (MHA)**: Классическое внимание с `num_heads=8` и `num_heads_kv=4`, обеспечивающее контекстуальную обработку данных.
3. **GatedMLP**: Многослойный перцептрон с гейтингом для нелинейных преобразований.

### Гибридные блоки
Основу модели составляют `n_layer=6` гибридных блоков (`HybridBlock`), которые объединяют Mamba2 и MHA через адаптивный гейтинг:
- Выходы Mamba2 и MHA взвешиваются с помощью обучаемой гейтинг-функции (`nn.Sequential` с `Softmax`),
- Остаточные соединения и нормализация (`LayerNorm`) применяются для стабилизации обучения.

### Калибровка и выходной слой
- **CalibrationModule**: Использует дополнительные лабораторные данные (`lab_feature_dim=5`), если они доступны, для калибровки предсказаний через гейтинг и трансформацию.
- **Output Head**: 
  - Без оценки неопределенности: Линейный слой с выходом размером `output_dim=2`.
  - С оценкой неопределенности (`estimate_uncertainty=True`): `UncertaintyHead` предсказывает среднее и дисперсию для каждого выхода, используя Negative Log Likelihood (NLL) в качестве функции потерь.

### Конфигурация
Ключевые гиперпараметры заданы в `HybridConfig`:
- `d_model=256` — размер скрытого пространства,
- `d_intermediate=512` — промежуточный размер для MLP,
- `dropout=0.1` — регуляризация,
- `learning_rate=1e-3`, `weight_decay=1e-2` — параметры оптимизации.

## Обучение и результаты
Модель обучалась в течение 20 эпох на видеокарте NVIDIA T4 с размером батча 256. Использовался оптимизатор `AdamW` с планировщиком `CosineAnnealingLR`. Однако гиперпараметры не были оптимально настроены, что могло повлиять на итоговую точность. Метрика качества — **RMSE (Root Mean Squared Error)** — вычислялась в исходных единицах (0–100). На полном тестовом наборе данных:
- **RMSE = 7.775886372273692**.

Этот результат демонстрирует среднюю ошибку около 7.78 единиц в диапазоне значений от 0 до 100 для обоих предсказываемых столбцов ("Гранулометрия 1" и "Гранулометрия 2"). Учитывая минимальную предобработку данных и неоптимальные гиперпараметры, это указывает на потенциал модели для дальнейшего улучшения.

## Реализация
Код модели разбит на модули, доступные в ветке `dev` репозитория [SUKUNA-AI/MAMBA-v2.1](https://github.com/SUKUNA-AI/MAMBA-v2/tree/dev/Desktop/Python/Python_projects/Мои%20блокноты/MAMBA_V2.1):
- `Mamba2` (`mamba_module.py`) — SSM-компонент,
- `MHA` (`mha_module.py`) — механизм внимания,
- `HybridBlock` (`hybrid_block.py`) — гибридный блок,
- `PulpSieveModel` (`model.py`) — основная модель,
- `TelemetryPreprocessor` (`preprocessing.py`) — предобработка данных,
- `UncertaintyHead` (`uncertainty_module.py`) — оценка неопределенности.

## Выводы
Наивная реализация гибридной MAMBA2 показала свою эффективность для предсказания гранулометрических характеристик на телеметрических данных. RMSE 7.78 при минимальной очистке данных и неоптимальных настройках свидетельствует о хорошей базовой производительности модели и её потенциале для промышленного применения.

## Будущие улучшения
На основе анализа текущих результатов и предложенных улучшений в документе "Улучшения модели PulpSieve" планируются следующие доработки:
- **Архитектурные улучшения**:
  - Внедрение `EnhancedMamba2` с Rotary Positional Embeddings, Stochastic Depth и спектральной нормализацией для повышения точности и стабильности.
  - Улучшение `EnhancedMHA` с обучаемой температурой и нормализацией слоев.
  - Оптимизация `EnhancedHybridBlock` с адаптивным гейтингом и пре-нормализацией.
- **Обработка данных**:
  - Усовершенствование `EnhancedTelemetryPreprocessor` с механизмом внимания к признакам и оптимизированными скользящими статистиками.
  - Улучшение `EnhancedCalibrationModule` с кросс-вниманием между телеметрией и лабораторными данными.
- **Оценка неопределенности**:
  - Переход к `EnhancedUncertaintyHead` с использованием смеси гауссовых распределений и учетом корреляции между выходами.
- **Обучение**:
  - Повторное обучение модели с оптимальными гиперпараметрами (например, увеличение `d_model` до 384–512, `n_layer` до 8–12, настройка `dropout` и `stochastic_depth_prob`).
  - Использование разогрева скорости обучения и градиентного клиппирования для стабилизации.
  - Применение смешанной точности (`use_mixed_precision=True`) для ускорения обучения на T4.
- **Предыдущий опыт**:
  - Модель до этого обучалась 20 эпох на видеокарте T4 с батчем 256 и неоптимальными гиперпараметрами, что будет исправлено в следующем цикле обучения.
- **Дополнительно**:
  - Более тщательная предобработка данных (удаление выбросов, нормализация).
  - Интеграция лабораторных данных для калибровки.
  - Эксперименты с ансамблированием (`use_ensemble=True`) для повышения точности.

Даныне улучшения позволят снизить RMSE, повысить стабильность модели и сделать её более пригодной для реальных промышленных сценариев.
